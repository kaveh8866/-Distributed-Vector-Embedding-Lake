5. Application-level leak surface
---------------------------------
- Qdrant requires an API key; compose refuses to start without one
  (`${QDRANT_API_KEY:?...}`).
- Worker and API run read-only with cap_drop ALL, so a compromised process
  cannot rewrite its own image.
- Instance metadata (user_data) carries cloud-init only: no `.env`, no key, no
  token. The deployed check confirmed the stack reads its key from the host
  `.env` at runtime.
- The retrieval API returns chunk payloads and latency; it does not echo the
  environment or database credentials.
- Terraform outputs are limited to addresses, OCIDs, sizes and an exposure
  inventory; the deploy hint carries no credential.
